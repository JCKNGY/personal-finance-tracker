# Personal Finance Tracker - Version 1 (Console + JSON)

## Goal
Create a console-based finance tracker that saves and loads transactions from a local JSON file.

## Required Features
- Add Transaction
- View Transactions
- Delete Transaction
- Monthly Summary
- Category Summary
- Save and Load Data from JSON

## Acceptance Criteria
- Add income and expense transactions
- View all transactions
- Delete transactions
- Monthly summary
- Category summary
- Data persists after restart
- Input validation
- Reject negative or zero amounts

## Stretch Goals
- Edit transaction
- Search by category
- Filter by date range
- Export CSV
- Unit tests
